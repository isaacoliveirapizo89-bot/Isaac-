# Certificados

Coloque nesta pasta os PDFs dos seus certificados da Fundação Bradesco.

Use estes nomes para que os links do portfólio funcionem:
- `desenvolvimento-web.pdf` — Crie um Site Simples Usando HTML, CSS e JavaScript
- `lgpd.pdf` — Lei Geral de Proteção de Dados (LGPD)
- `fundamentos-ti.pdf` — Fundamentos de TI: Hardware e Software

Os PDFs ainda precisam ser adicionados. Não publique documentos que contenham dados pessoais que você não queira deixar públicos.
